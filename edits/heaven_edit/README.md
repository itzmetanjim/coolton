# HEAVEN//ROOT — code-only edit

A 48-second vertical (1080x1920, 30 fps) pro-acceleration / cybersecurity edit.
Every frame and every sample is generated by the code in this folder. There is no
stock footage and no samples.

**Art style: "1-bit seraph".** Scenes are drawn at 360x640 and run through an
8x8 Bayer ordered dither into a three-colour palette (void black, bone white,
blood red). They are then scaled up 3x with nearest-neighbour and finished with
CRT scanlines, vignette, slice glitches, RGB split on hits, and beat-synced
punches and shake. A wireframe "biblically accurate" angel (rings of red-pupil
eyes, six wings) runs through the edit, alongside neural nets, hex rain, an
attack-arc globe, circuit traces carrying "blood" and an exponential compute
curve.

## Soundtrack

`music.py` synthesizes an original 140 BPM F-minor drift-phonk / industrial
track: distorted 808s, a pitched-cowbell lead, a formant "angel choir",
glitch blips for each typed letter, buzzers on WRONG, risers, impacts and an
ECG flatline. The track is timed so the song lyrics fit it. It has no vocals:
the lyrics appear on screen as kinetic type.

## Build

```bash
pip install numpy scipy pillow imageio-ffmpeg
ln -s "$(python -c 'import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())')" /usr/local/bin/ffmpeg
python render.py --out heaven_root.mp4            # synth soundtrack + video, about 5 min on 4 cores
```

### Using the real song instead

Everything is laid out in beats (`timeline.py`), so the visuals can be re-timed
onto any track:

```bash
python render.py --audio song.mp3 --bpm <song bpm> --offset <seconds>
```

`--offset` is the time in the audio where beat 0 falls. The first word slam
("MACHINE") is at beat 4, so `offset = (time "Machine" is sung) - 4 * 60 / bpm`. The lyric cue beats are listed in `timeline.py`
(`WORDS`, `SPELLS`, `LINES`). Nudge them there if the song's phrasing differs
from the 140 BPM layout.

Other flags: `--frames a:b` renders a preview range, `--crf` sets quality
(28 by default, about 80 MB; dithering is hard on codecs) and `--lossless` writes a lossless master.

For a sub-30 MB 720p cut (the 3px dither blocks map exactly to 2px):

```bash
python render.py --lossless --out master.mkv
ffmpeg -i master.mkv -vf scale=720:1280:flags=area -c:v libx264 -preset slow -b:v 4400k -pass 1 -an -f mp4 /dev/null
ffmpeg -i master.mkv -vf scale=720:1280:flags=area -c:v libx264 -preset slow -b:v 4400k -pass 2 \
       -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart heaven_root_720p.mp4
```
